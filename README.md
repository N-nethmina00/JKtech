# JKtech.lk Real E-Commerce Starter

Stack: HTML + CSS + JavaScript + PHP + MySQL.

## Setup
1. Put the `jktech` folder inside XAMPP `htdocs`.
2. Start Apache and MySQL.
3. MySQL is configured for port **3307** in `config/database.php`.
4. Import `database/jktech.sql` in phpMyAdmin.
5. Open `http://localhost/jktech/`.

This is the starter architecture. Product images, persistent DB cart, full order creation, payment gateway, advanced admin CRUD and production security hardening are next stages.
